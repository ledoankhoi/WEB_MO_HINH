# 9. Các hệ thống bên ngoài cần tích hợp

| Hệ thống | Mục đích | Mức độ ưu tiên |
| --- | --- | --- |
| Cổng thanh toán | Thanh toán trực tuyến | Cao nếu không chỉ dùng COD |
| Ngân hàng | Chuyển khoản, đối soát | Tuỳ phương thức thanh toán |
| Đơn vị vận chuyển | Báo phí, tạo vận đơn, theo dõi | Cao khi vận hành thật |
| Email/SMS | Gửi thông báo giao dịch | Cao |
| Lưu trữ media | Ảnh, video, file 3D | Cao |
| Analytics | Đo lường hoạt động | Trung bình |
| Hệ thống hoá đơn | Phát hành chứng từ theo quy định | Theo nhu cầu pháp lý |
| Nhà cung cấp đăng nhập | Đăng nhập bên thứ ba | Tuỳ chọn |
| Công cụ hỗ trợ khách hàng | Ticket hoặc chat | Tuỳ quy mô |

Mỗi tích hợp cần xác định rõ: hệ thống nào là nguồn dữ liệu chính, cách xác minh kết quả, cách xử lý lỗi, và cách đối soát khi hai hệ thống không đồng bộ.
